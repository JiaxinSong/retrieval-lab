
No — work_mem is not a single per-connection cap. It is a per-operation/per-process limit: each sort/hash operation generally may use up to work_mem (and hash tables multiply that by hash_mem_multiplier), multiple operations in a session and multiple sessions can each use work_mem, and resource limits like work_mem are applied separately to each parallel worker process as well [3][2][4].
